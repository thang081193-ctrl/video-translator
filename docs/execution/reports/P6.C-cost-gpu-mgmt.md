## 3) Locked Decisions In This Phase
- **Architecture decisions**:
  - **`collect_gpu_stats()` never raises**: outer try/except around subprocess + torch paths ensures the web layer always gets valid JSON. Error becomes a field in the response (`{"available": False, "error": ...}`).
  - **nvidia-smi is authoritative, torch.cuda is fallback**: nvidia-smi gives temperature + utilization which torch can't. torch fallback used only when nvidia-smi binary missing or crashes.
  - **Cache snapshot is cheap** (read-only dict peek) and always included regardless of GPU availability — even on CPU-only machines, users can see which Whisper/Demucs/EasyOCR models are cached.
  - **`_vram_guard_check` fail-loud** per user-locked decision: raise FatalError with actionable message ("disable --keep-original-bgm or restart server") rather than silently downgrading to custom_bgm. Prevents confused users asking why their output sounds different.
  - **Guard is scoped to dub+keep_original_bgm**: Whisper and EasyOCR have their own GPU fallback paths (P6.A sticky flag) so they don't need a hard guard.
  - **ETA constants are not env-overridable**: keeps tests deterministic. Users who want accurate ETAs should look at past run times in logs.
  - **ETA is advisory only**: never used for job control logic, only `/api/status` display. If it's wrong, UI shows wrong ETA but pipeline still runs correctly.
  - **Disk space check is opt-in via `REQUIRE_DISK_SPACE=1`**: default off so existing tests don't break. Docker/installer can set it to `1` to fail fast on undersized instances.
  - **Auto-stop test uses `monkeypatch.setenv` with `clear=True`**: prevents leakage of the dev machine's `CONTAINER_ID` (if any) into tests.
  - **Auto-stop tests use `web.worker.last_activity` directly** (not monkeypatching `time.time`) — simpler and doesn't break other tests that use `time.time()`.
  - **`eta_seconds` defaults to 0 on failure**: job still enqueues even if ffprobe or nvidia-smi fails. The UI should show "ETA unknown" when 0.
- **Config changes**: none (GPUConfig already added in P6.A)
- **API contract changes**:
  - **New**: `GET /api/gpu` — returns JSON with GPU state + cache snapshot
  - **Additive**: `/api/status` now includes `eta_seconds` field (0 if estimation failed)
  - Both changes are additive, no breaking changes
- **Error handling policy**:
  - `/api/gpu`: never raises, always 200 with valid JSON (may have `available: False`)
  - `_vram_guard_check`: raises FatalError on low VRAM (user-locked decision)
  - `auto_stop_check`: swallows subprocess errors to keep maintenance loop alive
  - `estimate_eta_seconds`: never raises (pure math over validated inputs)

## 8) Risks, Issues, And Mitigation
- **New risks**:
  - **nvidia-smi CSV format fragility**: future driver versions might change field order. Mitigated by named parsing in `_parse_nvidia_smi` (hardcoded field indexes) + fallback to torch.cuda. If nvidia updates the CSV, tests will fail before deploy.
  - **VRAM guard too aggressive**: 2048MB default could be wrong for some workloads. Mitigated by `VRAM_MIN_FREE_MB` env var override.
  - **ETA heuristic way off**: constants are based on "empirical Whisper medium on RTX 3060" but actual hardware varies. Advisory only — UI can display `ETA ~{n}m (estimate)` to set expectations.
  - **`create_job` added ffprobe call**: adds ~200ms latency to every upload. Wrapped in try/except so ffprobe failure defaults eta=0 and job still enqueues.
  - **Disk space probe may miss Windows symlinks**: `shutil.disk_usage` follows symlinks on Windows. Not a practical issue since Vast.ai runs Linux.
- **Known issues**: none introduced
- **Severity**: low
- **Mitigation in place**:
  - 43 new tests catch regression automatically
  - All new code paths have dedicated test coverage
  - `/api/gpu` has 5 tests guaranteeing non-500 behavior
  - VRAM guard boundary condition tested (strict less-than)
- **Rollback strategy**: `git revert` on the single P6.C commit. Behavior-preserving because all changes are additive (new module, new endpoint, new helpers). Reverting only removes features, doesn't break anything.
