## 1) Objective And Acceptance Gate
- **Business objective**: Faster processing per video on Vast.ai. Demucs subprocess overhead (~10-30s/job) eliminated. Mix `medium` + `large-v3` Whisper without reload thrashing. Avoid wasted GPU init attempts after a single CUDA failure.
- **Technical objective**:
  1. Process-wide sticky GPU/CPU flag — once any model loader trips on CUDA, all subsequent loaders skip GPU until process restart
  2. Whisper LRU model cache — keep both `medium` and `large-v3` resident (cache size 2, env-overridable)
  3. Demucs in-process `Separator` cache — replace subprocess `demucs.separate.main([...])` with `demucs.api.Separator()` reused across jobs; subprocess fallback for older demucs versions
  4. EasyOCR cache key simplified — drop `|gpu=...` suffix, use `gpu_state.should_use_gpu()` dynamically
  5. `torch.cuda.empty_cache()` between jobs to release fragmented VRAM
  6. New `GPUConfig` dataclass with env var overrides (`WHISPER_CACHE_SIZE`, `VRAM_MIN_FREE_MB`, `FORCE_CPU`)
- **Hard constraints**:
  - 337 baseline tests must still pass
  - No behavior change for happy paths
  - Public API of `transcribe`, `separate_audio`, `_get_ocr_reader` unchanged externally (only internal cache structure)
  - All new helpers ≤ 50 LOC (Gate 3)
- **Non-goals**:
  - Whisper batched inference (`BatchedInferencePipeline`) — risky, defer
  - Parallel Whisper + OCR same GPU — VRAM unsafe
  - Model auto-downgrade — defer to user choice

## 3) Locked Decisions In This Phase
- **Architecture decisions**:
  - **Sticky GPU flag is process-wide**: once tripped, only resolved by restart. Acceptable on Vast.ai because restarts are cheap. Documented in `gpu_state.py` docstring.
  - **`gpu_state.py` does NOT import torch at module level**: keeps unit tests fast and importable on CPU-only dev boxes. `empty_cuda_cache()` does lazy import inside try/except.
  - **LRU cache key includes device**: same model on GPU vs CPU is 2 separate cache entries. After GPU failure, the GPU entry is explicitly evicted to free VRAM, then a CPU entry is created.
  - **Demucs in-process cache uses `device|model` key**: caller decides device based on `gpu_state`. After OOM, `_evict_gpu_separator(model)` drops only the GPU entry.
  - **Subprocess fallback path preserved byte-for-byte from P5**: any user with older demucs (no `demucs.api`) gets the exact same behavior as before. Detected by catching `ImportError` from `from demucs.api import Separator`.
  - **EasyOCR `_get_ocr_reader` no longer takes `gpu` arg**: cache key is now lang-list only. The internal try/except handles GPU init failure + CPU retry. Reduces caller complexity.
  - **`empty_cuda_cache()` is best-effort**: wrapped in outer try/except in `run_pipeline()` so a completed job never fails because cleanup couldn't run.
- **Config changes**:
  - New `GPUConfig` dataclass: `whisper_cache_size=2`, `vram_min_free_mb=2048`, `force_cpu=False`
  - Env vars added: `WHISPER_CACHE_SIZE`, `VRAM_MIN_FREE_MB`, `FORCE_CPU`
  - New `_env_bool()` helper in `config.py` for boolean env var parsing (truthy: `1`, `true`, `yes`, `on`)
- **API contract changes**:
  - **Internal**: `pipeline.ocr.detector._get_ocr_reader(langs: list[str])` — signature change (dropped `gpu` arg). Only caller is `detect_text_regions()`, updated in same commit.
  - **Internal**: `pipeline.dub.separator` exposes new private helpers (`_get_separator`, `_separate_via_api`, `_separate_via_subprocess`, `_install_soundfile_save_patch`, `_evict_gpu_separator`). Public `separate_audio()` signature unchanged.
  - **Public**: `pipeline.transcribe.transcribe()` signature unchanged. `pipeline.dub.build_dubbed_audio()` unchanged.
- **Error handling policy**: gpu_state's `mark_gpu_unavailable()` is idempotent — second call is a no-op (preserves first reason for debugging).
- **Why these decisions were chosen**:
  - "No torch import at module level" → tests can run on Windows dev box without GPU
  - "LRU cache key includes device" → enables Mix workflow (medium on GPU + large-v3 on GPU + CPU fallback during failure)
  - "Subprocess fallback preserved" → backward compat for production environments with older demucs

## 4) Implementation Details

### 4.1 Pipeline Changes
- **GPU state module (NEW)**: 95 LOC, 5 public functions, no torch dependency at module level. Thread-safe via single `threading.Lock()`. Reset helper for tests.
- **Whisper transcribe**: Refactored from single-dict cache to `OrderedDict` LRU at `cfg.gpu.whisper_cache_size` (default 2). Cache key is 3-tuple `(model_name, device, compute_type)`. New `_evict_if_needed()` drops oldest entries when over budget and calls `gpu_state.empty_cuda_cache()`. Process-wide sticky GPU flag now wired through `_try_load_gpu()` and `_fallback_to_cpu()`.
- **Demucs separator**: Replaced subprocess `demucs.separate.main([...])` per-call with in-process `demucs.api.Separator` cache. New helpers split into 5 single-responsibility functions (each ≤ 50 LOC). On GPU OOM: evict cached GPU separator → mark gpu_state unavailable → retry on CPU → if both fail, raise `DegradedError(feature="demucs")` (preserves P5.1 contract). Older demucs versions (no `demucs.api`) automatically fall back to subprocess path. Torchaudio monkey-patch moved to `_install_soundfile_save_patch()` and called once (not per call).
- **EasyOCR detector**: `_get_ocr_reader(langs)` simplified — drops `gpu` arg, reads `gpu_state.should_use_gpu()` internally, handles RuntimeError → CPU retry inside the helper. Cache key drops `|gpu=...` suffix. Caller `detect_text_regions()` reduced from 5-line try/except block to 1-line `reader = _get_ocr_reader(langs)`.

### 4.2 Web App Changes
- `web/pipeline_runner.py`: added `from pipeline.gpu_state import empty_cuda_cache` import; called at end of `run_pipeline()` after temp dir cleanup, wrapped in try/except to never fail completed job.

## 8) Risks, Issues, And Mitigation
- **New risks**:
  - **`demucs.api.Separator` API surface variation**: `separate_audio_file()` exists in demucs 4.0.1+; older versions don't have it. Mitigated by `_separate_via_subprocess` fallback (preserves P5 behavior byte-for-byte).
  - **Sticky CPU flag is process-wide**: must restart uvicorn to recover GPU after a transient driver blip. Acceptable on Vast.ai (cheap restart) but worth documenting in runbook (deferred to P6.B).
  - **In-process Demucs holds VRAM continuously**: ~1.8-2.2 GB resident even when no dub job is running. With Whisper medium (1.5GB) + EasyOCR (~1GB) + Demucs (~2GB) = ~4.5-5 GB always-on. Still fits in 12 GB RTX 3060 with comfortable headroom.
  - **LRU eviction during a running job**: if `_get_model('large-v3')` is called while `medium` is mid-transcribe AND cache_size=1, the medium model would be evicted while in use. Mitigated because: (a) cache_size default is 2, (b) worker is single-threaded sequential (verified at `web/worker.py:24` comment "process one video at a time"). Not a concern in practice.
- **Known issues**: none
- **Severity**: low
- **Mitigation in place**:
  - Subprocess fallback preserves backward compat
  - All locks have minimal critical sections (sub-microsecond)
  - `empty_cuda_cache()` is best-effort, never raises into the pipeline
  - All new helpers ≤ 50 LOC for easy review
- **Rollback strategy**: `git revert` on the single P6.A commit. Behavior-preserving for happy paths; would lose the 28 new tests + LRU + sticky flag + empty_cache.
