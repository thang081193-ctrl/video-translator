## 3) Locked Decisions In This Phase
- **Architecture decisions**:
  - **Caller-owned temp dirs**: `separate_audio` no longer creates its own scratch directory. The caller (mixer.py) wraps its call in a `with temp_dir("demucs", base_dir=output_dir) as demucs_dir:` and passes the result. This makes cleanup ownership visible at the call site and composable with sibling temp dirs (e.g. `_tts_temp`).
  - **Nested context managers for `keep_original_bgm` mode**: because `stems["no_vocals"]` returns a file *inside* `_demucs_temp`, the mix step MUST run BEFORE exiting the demucs `with` block. Solution: nest `with temp_dir("demucs", ...)` INSIDE the `with temp_dir("tts", ...)` block so `_mix_voice_and_bgm` has both the dubbed raw track and the separated BGM stem available.
  - **3 helpers (not 2)**: original plan called for `_build_concat_track` (1 helper). First implementation produced a 102 LOC helper — still over Gate 3. Split further into `_generate_tts_pieces` (45), `_collect_concat_pieces` (41), `_ffmpeg_concat` (28). Each helper now represents a single responsibility.
- **Config changes**: none
- **API contract changes**:
  - **Internal**: `pipeline.dub.separator.separate_audio(audio_path, demucs_dir, ...)` — parameter rename only, positional call sites unaffected. Only caller is `pipeline/dub/mixer.py`.
  - **Public**: `pipeline.dub.build_dubbed_audio(...)` signature **unchanged**. CLI + Web callers don't care.
- **Error handling policy**: `RuntimeError("No TTS segments generated")` preserved verbatim in `_generate_tts_pieces` (will migrate to `FatalError` in P5.1).
- **Why these decisions were chosen**:
  - Gate 3 enforcement: 102 LOC helper still violates the spirit of "single responsibility". Three-way split maps cleanly onto the three distinct phases (TTS generation, silence-gap interleaving, ffmpeg concat).
  - Caller-owned temp dirs follow the "composability" principle in `phase-workflow.md` lines 261-273.

## 8) Risks, Issues, And Mitigation
- **New risks**:
  - **Nested `with temp_dir` inside `keep_original_bgm` branch** — if `_mix_voice_and_bgm` is accidentally moved OUTSIDE the `with temp_dir("demucs")` block in a future edit, `stems["no_vocals"]` will point to a deleted file. Mitigation: docstring on `separate_audio` explicitly calls this out. Long-term: consider returning the stems as bytes or copying them into the parent `tts_dir` before exiting demucs context.
- **Known issues**:
  - `build_dubbed_audio` orchestrator at 58 LOC is over Gate 3's 50 LOC guideline (signature dominates). A `DubParams` dataclass would fix this properly but is out of scope.
  - Dead temp-dir cleanup loops in `video_translator.py:227,259,311` and `web/pipeline_runner.py:270` now reference directories that will never exist. Harmless (defensive, `os.path.isdir()` returns False) but can be removed in a future docs-only cleanup.
- **Severity**: low
- **Mitigation in place**:
  - Docstring on `separate_audio` documents the caller-ownership constraint
  - Test suite enforces no regression on public `build_dubbed_audio` signature via `test_pipeline_integration.py`
- **Rollback strategy**: `git revert` on the single P5.0 commit — the refactor is behavior-preserving, so rollback is safe at any point.
