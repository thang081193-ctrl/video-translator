# Source of truth for what is actually imported:
#   - faster-whisper / ctranslate2  : scan (manifest.py, device='cpu' int8) + QA (qa_voice_mix.py 'tiny')
#                                     + the brandpass GPU voice-gate (transcribe.py)
#   - demucs.api.Separator          : pipeline/dub/separator.py  (REQUIRES >=4.0 for the .api module)
#   - edge_tts                      : pipeline/dub/tts.py, voiceover  (cloud TTS — SPOF, no offline fallback)
#   - easyocr / cv2 / PIL / numpy   : pipeline/ocr (detector maps zh->ch_sim, ja, ko + en/vi)
#   - soundfile                     : audio I/O
#   - fastapi / uvicorn / multipart : web_app serving
#   - google-genai                  : translation provider factory
#   - python-dotenv                 : .env loading
#
# Versions are reconciled to the audit's recommended pins; freeze with
# `pip freeze` after the first successful cu130 build to lock transitives.
# ---------------------------------------------------------------------------

# ---- Torch: DO NOT pin / reinstall here ------------------------------------
# The vastai/pytorch:cuda-13.1.2-auto base image ALREADY ships torch + torchaudio
# built for cu130. Reinstalling from the cu121 index is the live Dockerfile:38 bug
# and silently CPU-falls the brandpass voice-gate + Demucs on a cu130 box.
# setup.sh VERIFIES torch.cuda.is_available() (exit 7) and NEVER pip-reinstalls it.
# If you ever must reinstall, use --index-url https://download.pytorch.org/whl/cu130
# (torchaudio 2.12 is absent on the cu130 index per memory — use 2.11.x).
